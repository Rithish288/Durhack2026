# cube_encoder_app

1. Install Python 3 (3.9 or newer).
2. In this folder:  python -m venv .venv  &&  .venv/bin/pip install -r requirements.txt
   (Windows: .venv\Scripts\pip install -r requirements.txt)
3. Run:  .venv/bin/python cube_encode_app.py        (Windows: .venv\Scripts\python cube_encode_app.py)
   A browser tab opens automatically. Works fully offline.

CLI alternative:
   (web only) the Export button saves cube_<time>_A.png and _B.png
